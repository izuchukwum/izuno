# IZUNO — Student Services Booking Website

IZUNO is a web project designed to make student life easier by providing a simple way to request everyday services in one place.

## About the Project

The project is being developed as a beginner-friendly web development project using HTML, CSS, and JavaScript.

## Current Features

- Service cards for barbing, nail services, and laundry pickup and delivery.
- Booking form for name, phone number, contact address, and preferred date.
- Required-field validation.
- Restriction against selecting past booking dates.
- Confirmation message after form submission.
- Ability to switch between services and clear previous form details.
- Responsive layout styling for desktop and mobile screens.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Status

IZUNO is currently a work in progress. The front-end booking flow is implemented, and the website's design and mobile responsiveness are being improved.

**Note:** Booking confirmations currently appear in the browser. Persistent booking storage and actual service-provider notifications have not yet been implemented.

## Running the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using a local development server, such as the Live Server extension.
